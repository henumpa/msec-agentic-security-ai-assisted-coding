# MSec Agentic Security - AI-Assisted Coding

Hands-on coding exercises focused on how engineers collaborate with AI coding
agents to understand unfamiliar code, diagnose failing tests, and deliver clean,
correct solutions. Use your preferred AI coding assistant; the emphasis is on
your technical judgement, how you guide the agent, and how you review its work.

## Choose your exercise

| Level | Exercise | Scope |
|---|---|---|
| [SWE-2 Engineer](swe-2-engineer/README.md) | Product Catalog Service | Fix pagination, resource creation, input validation, and not-found behaviour. |
| [Senior Engineer](senior-engineer/README.md) | Product Catalog Service | Complete both required parts: fix the failing behaviours and implement end-to-end image upload. |
| [Principal Engineer](principal-engineer/README.md) | Order Processing Service | Address idempotency, inventory reservation, cancellation, and order totals, with a fulfillment saga stretch goal. |

## Getting started

Choose your level, then pick **C#**, **Python**, or **Java** and follow the setup
instructions in that exercise's README. Azure dependencies are simulated
in-memory, so no cloud resources are needed.

The failing tests describe the expected behaviour. Keep the tests intact, use
the simulators, and review every AI-generated change before accepting it.
